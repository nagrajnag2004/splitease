🚀 **Excited to share my latest full-stack project: SplitEase — A Smart Splitwise Clone built with the MERN Stack!** 💸

Ever been on a group trip or shared an apartment where figuring out "who owes whom" turned into a chaotic nightmare of multiple transfers? 🤯 

I built **SplitEase** to solve this exact problem! It not only tracks shared expenses but also uses a **Greedy Min Cash-Flow Algorithm ($O(n \log n)$)** to simplify debt graphs—minimizing the total number of transactions required across group members so nobody overpays or underpays.

---

### 🔥 Key Features & Capabilities:

🧠 **Greedy Debt Simplification Engine**: Reduces complex webs of multi-person debts down to the fewest direct transfer settlements (e.g., converts $A \rightarrow B \rightarrow C$ into a single direct $A \rightarrow C$ payment).
⚖️ **3 Flexible Split Modes**:
  - **Equal Split**: Automatically divides bills with penny-rounding logic.
  - **Exact Split**: Custom dollar allocations per participant with real-time validation.
  - **Percentage Split**: Split by percentages (validated to sum to 100%).
👥 **Groups & 1-on-1 Friend Splits**: Organize expenses by *Trips 🏖️*, *Home/Apartment 🏢*, *Couples ❤️*, or *Projects 💻*, as well as direct 1-on-1 friend bills outside groups.
📊 **Interactive Spending Analytics**: Visual doughnut charts breakdown spending by category (Food, Rent, Travel, Entertainment).
🎉 **Instant Settle-Up & Celebrations**: Pre-filled settlement modal backed by algorithmic recommendations + celebratory confetti bursts upon payment!

### 💻 Tech Stack:

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons, Chart.js
- **Backend**: Node.js, Express.js REST API, JWT Authentication, Bcrypt
- **Database**: MongoDB Atlas Cloud
- **Deployment**: Vercel (Frontend) + Render (Backend API)
